# User-controlled scan review size

Brian requested a size preference after the fixed desktop comparison was first too large and then too small. Simple review now has a Card size slider beside the batch actions, with75-200% keyboard-accessible control, a percentage and Reset to100%. Both images change together. Focused and two-column layouts share the choice. The setting belongs to the current user on this browser and survives batch navigation/reload; blocked storage still allows session sizing, and invalid saved values fall back to100%.

The image pair keeps its requested width until it reaches available page width. Details wrap below a larger pair rather than shrinking just one image or overflowing the page. This is a display preference; it does not alter originals, canvas coordinates, recognition, reviews, Inventory selection or transactions. Advanced evidence mode keeps its existing tools/presentation.
